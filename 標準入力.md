## パターン 1｜数値が1つ

```
42
```

```typescript
const lines = require("fs").readFileSync("/dev/stdin", "utf8").split("\n");

const N = Number(lines[0]);
```

## パターン 2｜同じ行に数値が複数（スペース区切り）

```
3 14 15
```

```typescript
const lines = require("fs").readFileSync("/dev/stdin", "utf8").split("\n");

const [A, B, C] = lines[0].split(" ").map(Number);
```

---

## パターン 3｜1行目が件数 N、続く N 行に数値が1つ

```
3
10
20
30
```

```typescript
const lines = require("fs").readFileSync("/dev/stdin", "utf8").split("\n");

const N = Number(lines[0]);
const values = Array.from({ length: N }, (_, i) => Number(lines[i + 1]));
```

---

## パターン 4｜1行目が件数 N、続く N 行にスペース区切りの数値

```
3
1 2
3 4
5 6
```

```typescript
const lines = require("fs").readFileSync("/dev/stdin", "utf8").split("\n");

const N = Number(lines[0]);
const pairs = Array.from({ length: N }, (_, i) =>
  lines[i + 1].split(" ").map(Number)
);
// pairs[0] → [1, 2]
// pairs[1] → [3, 4]
```

---

## パターン 5｜1行目に N と M、続く N 行に M 個の数値（グリッド・行列）

```
2 3
1 2 3
4 5 6
```

```typescript
const lines = require("fs").readFileSync("/dev/stdin", "utf8").split("\n");

const [N, M] = lines[0].split(" ").map(Number);
const grid = Array.from({ length: N }, (_, i) =>
  lines[i + 1].split(" ").map(Number)
);
// grid[0][1] → 2
// grid[1][2] → 6
```

## パターン 9｜行数が指定されない（EOF まで読む）

```
1 2
3 4
5 6
```

```typescript
const lines = require("fs")
  .readFileSync("/dev/stdin", "utf8")
  .split("\n")
  .filter((line: string) => line.trim() !== "");

for (const line of lines) {
  const [A, B] = line.split(" ").map(Number);
  console.log(A + B);
}
```
